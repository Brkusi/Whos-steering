# Shared link preview

Open Graph and Twitter image metadata use the existing company logo at `https://whossteering.com/ws-logo.png` on all routes. Product structured data retains the corresponding product photograph. The HTML template, prerendered pages and client navigation share this choice, including the Infiniti airbag configurator's static head. Existing messaging/social previews can remain in the sharing service's cache until it fetches the URL again.
